# Paper build instructions

## Contents

```
main.tex                 the paper (6-page main body + appendix)
figures/*.pdf            5 vector figures, generated by src/make_figures.py
code/*.py                the 11 source files, pulled into the appendix
pagecheck.py             rough page-budget estimator (no LaTeX needed)
```

## Before you build: two edits

**1. Author block.** Open `main.tex`, find the two lines marked `% <<<`
(around line 55) and replace:

```latex
\textit{Department of Computer Science and Engineering} \\ % <<<
\textit{[Your Institution]} \\                             % <<<
```

with your actual department and institution. Everything else in the author
block is already formatted to IEEE requirements.

**2. Verify the references.** All 19 are real, published works, but you should
open each one and confirm the volume/page numbers before submitting. Never
submit a citation you have not seen yourself.

## Building

### Option A — Overleaf (recommended, nothing to install)

1. Go to overleaf.com, create a blank project
2. Upload `main.tex`, then the `figures/` and `code/` folders
3. Set the compiler to **pdfLaTeX** (Menu → Compiler)
4. Click Recompile

Overleaf already has `IEEEtran`, so nothing else is needed.

### Option B — Local MiKTeX / TeX Live

```
pdflatex main
pdflatex main
```

Run it twice so cross-references and citations resolve.

## Checking the 6-page limit

The main body must end at page 6, immediately after the references. The
appendix that follows is deliberately outside the limit.

Estimated budget (from `pagecheck.py`):

| Component | Pages |
|---|---|
| Title + abstract | 0.30 |
| Body text (3,440 words) | 3.44 |
| 5 double-column figures | 1.64 |
| 3 tables | 0.34 |
| References | 0.26 |
| **Total** | **~5.98** |

This is an estimate, not a compile. Check the real page count after building.

### If it runs to 7 pages

Try these in order — each is safe and preserves content:

1. Reduce figure heights in `src/make_figures.py` (the `figsize` height
   argument), then re-run it. Dropping each of figures 2–5 from 2.4 to 2.1
   inches saves roughly a third of a page.
2. Shorten Section IV-F (Limitations) — it is the most compressible section.
3. Move Table I into the text as a sentence.

### If it runs to 5 pages

Increase the figure heights, or restore detail to Related Work.

**Do not** change margins, font sizes, column widths or line spacing. That
would break the template.

## Regenerating figures

If you re-run any phase and the numbers change:

```
python src/make_figures.py
```

then copy the new PDFs into `paper/figures/`. The numbers quoted in the text
would also need updating — they are listed in Section IV.
